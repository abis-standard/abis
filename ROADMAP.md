# ABIS — Public Roadmap

**Version:** Public v0.1  
**Status:** Public concept release

This roadmap describes **planned public evolution**. Dates and deliverables are indicative and subject to change.

---

## v0.1 — Public concept and architecture (current)

**Target:** 2026-09-16 public launch

| Deliverable | Status |
| --- | --- |
| Public repository (concept documents) | In progress |
| README, CONCEPT, SCOPE, ARCHITECTURE | This release |
| Public terminology | This release |
| Public governance and contribution guidelines | This release |
| Disclosure gate | This release |
| Normative specifications | Not in v0.1 |
| Reference implementation | Not in v0.1 |
| Certification | Not in v0.1 |

**Goal:** Establish a clear, protocol-neutral public vocabulary for Business Interaction and Business Outcome across agents, protocols, and business systems.

---

## Validation and Adoption Path

ABIS is intended to evolve through real-world validation rather than through declaration alone.

```text
Public Concept
    → Industry Validation
    → Multi-company PoC
    → Interoperability Validation
    → Specification Evolution
    → De Facto Adoption
```

De Facto Adoption represents a possible future stage that would depend on practical use, validation, and adoption across multiple organizations and systems. It is not the current status of ABIS Public v0.1.

## Long-Term Vision

Following meaningful real-world adoption, future exploration may include:

```text
Global Validation
    → International Standardization
```

This is a long-term aspiration. ABIS Public v0.1 is not an international standard, and no formal international standardization status is implied by this roadmap.

---

## Non-goals for public v0.1

- publishing private implementation
- publishing runtime or validation harness
- publishing certification requirements
- publishing legal or patent material
- claiming standardization body status
